Workers' compensation classification is one of the highest-risk insurance decisions an SPF contractor makes — not because the exposure is unusual, but because misclassification can result in surprise audit charges that severely affect cash flow.

Getting it right starts with understanding how spray foam applicators are classified.

## NCCI Class Codes for SPF Applicators

The National Council on Compensation Insurance (NCCI) publishes the classification system most states use for workers' comp. There is no single NCCI class code dedicated exclusively to SPF application — applicators typically fall into one of several codes depending on the type of work performed:

**Code 5183 — Plumbing, Heating, Ventilation:** This code covers mechanical insulation work and is used in some states for SPF applicators performing building insulation.

**Code 5645 — Carpentry — Dwellings:** Used in some states for residential SPF work where spray foam is part of building envelope work.

**Code 5537 — Heating/AC/Ventilation Work:** Applied in some markets for SPF work adjacent to HVAC systems.

**State-specific codes:** Many states that operate outside NCCI (California, New York, New Jersey, Texas, among others) have their own classification bureaus with state-specific codes that may differ from the NCCI framework.

The critical point: there is no one correct answer for SPF applicators across all states. Class code assignment must be verified state by state, carrier by carrier, and for each application type (residential insulation, commercial insulation, SPF roofing, agricultural).

## Dual-Wage Rules

Several states — including California, Arizona, and others — apply dual-wage rules to WC classification. Under dual-wage rules, a single class code splits into two rate tiers based on the worker's hourly wage:

- Workers earning above the threshold (e.g., $34/hr in California) are rated at a lower rate
- Workers earning below the threshold are rated at a higher rate

For SPF contractors with crews that include both higher-paid applicator operators and lower-paid helpers, dual-wage allocation can significantly affect premium. Failing to apply dual-wage rules correctly — or applying them to the wrong employees — can result in either overpayment at policy inception or a large audit charge at year-end.

## Payroll Allocation

WC premium is calculated on payroll. For SPF contractors with mixed operations, accurate payroll allocation across class codes is essential:

**Applicator/operator payroll:** The highest-rated payroll — spray foam application crew members actively operating proportioners and spray guns.

**Helper/laborer payroll:** Crew members who assist with setup, material handling, and cleanup but don't operate spray equipment. May qualify for a lower class code in some states.

**Driver payroll:** Employees whose primary job is operating commercial vehicles (SPF rig transport). Driver classification is separate from applicator classification in most states.

**Clerical payroll:** Office staff, estimators, and administrative employees. Clerical code rates are significantly lower than applicator rates. Clerical employees must not perform any field work — if a clerical employee visits a job site, the clerical exemption is voided.

Misallocating payroll — for example, coding all employees as applicators when some are drivers or clerical — results in overpaid premium. Coding applicators as clerical results in an audit charge.

## The WC Audit

WC policies are written on estimated payroll and adjusted at year-end audit. The auditor reviews:
- Actual payroll by employee
- Employee classification by job function
- Certificates of insurance for subcontractors

For SPF contractors, audit risk is elevated in several areas:

**Subcontractor add-back:** If you use 1099 subcontractors without current WC certificates, the auditor will typically add their labor cost to your payroll at the applicable SPF applicator rate. This can produce a large, unexpected audit charge.

**Crew misclassification:** If applicators are coded under a lower-rated clerical or driver code during the policy year, the auditor will reclassify them at the correct applicator rate.

**Dual-wage errors:** If dual-wage thresholds aren't applied correctly, the auditor will recalculate.
